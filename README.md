# AgriCoopLedger

A record-keeping system for agricultural cooperatives in Rwanda. It replaces paper-based produce collection and farmer payment records with a single digital ledger.

> Status: early stage. Requirements and architecture are in progress. No code has been written yet.

## Problem

Cooperatives in Rwanda commonly record produce intake and farmer payments on paper. This makes it hard to:

- Track how much each farmer delivered and when
- Calculate and verify what each farmer is owed
- Keep a reliable payment history
- Produce reports for members and management

## Goals

- Record produce collected from each farmer
- Calculate amounts owed and record payments
- Keep a clear, auditable history per farmer and per cooperative
- Provide simple reports for cooperative staff

Detailed functional and non-functional requirements live in the SRS (see Documentation).

## Scope

This is a solo course project for Introduction to Software Engineering at African Leadership University (ALU), Kigali. It is built for class and is not intended as a production system.
